# 한국GPT협회 수달일보

한국GPT협회에 다니는 수달 사원이 매일 아침 골라오는 AI 뉴스와 4컷 웹툰. 협회 오픈채팅방에 매일 올릴 페이지입니다.

- 주소: https://koreagpt.github.io/sudal-news
- 운영자용 게시글 복사: https://koreagpt.github.io/sudal-news/share/

## 매일 하는 일

```
python daily.py
```

1. 9개 RSS(AI타임스, 지디넷코리아, 전자신문, 블로터, 구글뉴스, OpenAI, Google AI, TechCrunch, The Verge)에서 최근 36시간의 AI 기사를 모읍니다.
2. GPT가 6건을 골라 한국어 제목·요약·"수달 한마디"를 쓰고 `data/news/날짜.json`에 저장합니다.
3. 그중 하나로 수달 사원 4컷 웹툰을 만듭니다 (아래 "웹툰 자동 생성").
4. `public/`에 페이지를 만듭니다. 오늘 페이지, 날짜별 페이지(`d/날짜/`), 지난 호(`archive/`), 운영자용 복사 페이지(`share/`), 카톡 썸네일(`og/날짜.jpg`).

### 키가 없을 때

`OPENAI_API_KEY`가 없거나 API 오류가 나면 기본 모드로 발행합니다. 국내 기사만 키워드 점수로 고르고 원제목만 보여주며, 웹툰은 가장 최근 것을 그대로 씁니다.

- 링크는 항상 실제 수집한 기사에서 가져오며, AI가 만든 링크는 쓰지 않습니다.
- 기사 전문은 가져오지 않습니다. 제목·짧은 요약·원문 링크만 보여줍니다.

## 웹툰 자동 생성

컷온 웹툰 제작 스킬의 원칙(인물 고정값 유지, 짧고 정확한 대사, 가상 상황 표기, 결과물 검수)을 자동화했습니다.

1. **소재**: GPT가 뉴스를 고를 때 웹툰으로 만들기 좋은 기사와 아이디어도 함께 고릅니다.
2. **대본**: 제목, 4컷 장면·말풍선(18자 이내), 마무리 두 줄, 이미지 설명을 씁니다.
3. **작화**: GPT 이미지가 수달 인물기준(`data/reference/sudal-character.jpg`)과 첫 웹툰을 참고해 그립니다. 1차는 `medium` 화질로 그립니다.
4. **검수**: GPT가 완성 그림을 보고 컷 수, 한글 오탈자, 수달 외형, 실존 로고·인물을 확인합니다. 통과 못 하면 지적 사항을 반영해 `high` 화질로 한 번 더 그립니다.
5. 두 번 모두 통과 못 하면 어제 웹툰을 유지하고, 시안은 Actions 실행 결과의 `webtoon-drafts`에 7일간 남깁니다.

모델과 화질은 `config.json`의 `curation`, `webtoon`에서 바꿉니다.

### 설정집 (`data/bible.json`)

애니메이션 작화·표정·행동·배경 스킬의 기준표를 한 파일로 모았습니다. 대본·작화·검수가 매일 이 파일을 읽습니다.

- **그림체**: 따뜻한 일상 생활툰(주 S01, 보조 S12), 선·색·빛·배경 묘사량 규칙.
- **수달 사원**: 고정 외형, 허용 변형(눈꺼풀·입·귀·꼬리), 금지 사항, 성격과 연기 습관.
- **조연**: 너구리 대리(사내 소식통), 거북 팀장(확인을 챙김). 수달과 다른 종·실루엣이라 헷갈리지 않습니다.
- **장소**: 수달 자리·탕비실·회의실·집·지하철의 고정 배치와 빛.
- 대본은 컷마다 알려줄 것(beat), 샷 크기, 장소, 배경 밀도(establishing/context/contact/none), 시선·손·자세 연기를 정합니다.
- 검수는 글자·수달 동일성에 더해 조연이 주인공과 헷갈리지 않는지 확인하고, 시선·접촉 문제는 기록합니다.

인물이나 장소를 바꾸고 싶으면 이 파일만 고치면 다음 웹툰부터 반영됩니다.

## 옵션

```
python daily.py --basic                    # GPT 없이 기본 모드 (웹툰 없음)
python daily.py --webtoon-only             # 오늘 뉴스는 두고 웹툰만 다시
python daily.py --webtoon-only --topic 3   # 오늘 3번 뉴스로 웹툰 다시
python daily.py --build-only               # 수집 없이 페이지만 다시
python daily.py --date 2026-10-21
```

## 웹툰 직접 넣기

1. 이미지를 `data/webtoons/`에 넣습니다 (JPG 권장).
2. `data/webtoons.json`에 항목을 추가합니다. `date`가 같은 날 페이지에 "오늘의 수달 사원"으로 나오고, 그날 웹툰이 없으면 가장 최근 웹툰이 "수달 사원 웹툰"으로 나옵니다.
3. `python daily.py --build-only`

## 미리보기

```
python -m http.server 8765 --directory public
```

브라우저에서 http://localhost:8765 를 엽니다.

## 설정 (`config.json`)

- `site.base_url`: 배포 주소. 카카오톡 미리보기에 쓰입니다.
- `site.links`: 바닥글의 교육 안내 버튼 (기업교육 kgpt.or.kr, 온라인교육 gptkoreaclass.com).
- `site.repo`: 복사 페이지의 "웹툰 다시 만들기" 안내에 쓰는 GitHub 저장소.
- `feeds`: 뉴스 소스. `ai_only: false`인 일반 IT 매체는 AI 키워드가 있는 기사만 고릅니다.

## 자동 발행 (GitHub Actions)

`.github/workflows/daily.yml`이 매일 06:30(한국 시간)에 뉴스와 웹툰을 만들어 저장소에 기록하고 GitHub Pages로 배포합니다. 컴퓨터를 켜 둘 필요가 없습니다.

- 저장소 Settings → Secrets and variables → Actions 에 `OPENAI_API_KEY`를 등록해야 GPT 요약과 웹툰이 동작합니다.
- Actions 탭(또는 GitHub 앱) → "수달일보 발행" → Run workflow 에서 직접 실행할 수 있습니다.
  - `full`: 뉴스와 웹툰을 새로 만듭니다.
  - `webtoon`: 웹툰만 다시 만듭니다. `topic`에 뉴스 번호를 넣으면 그 뉴스로 만듭니다.
  - `build`: 페이지만 다시 만듭니다.
- 웹툰 이미지·디자인·설정을 바꿔 올리면 페이지만 다시 만듭니다.
- 매일 봇이 `data/`에 기록을 올리므로, 이 폴더에서 고치기 전에 `git pull`을 먼저 합니다.

## 오픈채팅방에 올리기

1. `배포주소/share/` 를 엽니다 (운영자용, 검색엔진 비노출).
2. 오늘 웹툰을 확인합니다. 별로면 "웹툰 다시 만들기" 안내대로 다시 만듭니다.
3. "게시글 복사하기"를 누르고 오픈채팅방에 붙여 넣습니다.
4. 게시글 속 링크는 날짜별 주소(`/d/날짜/`)라서 카카오톡 미리보기에 그날 썸네일이 뜹니다.

카카오톡은 한 번 읽은 미리보기를 오래 기억합니다. 썸네일을 고친 뒤에도 옛 이미지가 보이면 [카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 해당 주소의 캐시를 지웁니다.
